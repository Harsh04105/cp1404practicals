## Code Reviews

### What have you learned from being reviewed by other people?

I realised that code that works is not the same as code that is clear and maintainable. Reviewers often picked up naming, structure and duplication issues that I stopped seeing once my code ran, and their comments pushed me to write in a more cleaner consistent style.


### What have you learned from doing code reviews of other people?

Reviewing other people’s code made me much better at spotting problems in my own work. Such as repeated logic, missing docstrings, and it also showed me different ways to solve the same problem that were sometimes simpler than my approach.
